# Vibe Lab

两个纯本地的浏览器视觉玩具。**单文件、零依赖、不联网、不上传任何数据。**

在线玩 👉 https://xiaxia0717.github.io/vibe-lab/

---

## 浮影 Drift · 照片流动壁纸生成器

**[drift.html](drift.html)** — 选一张照片，它变成会流动的壁纸。

| 效果 | 出来是什么样 |
| --- | --- |
| 液态 | 照片像浸在水里，缓慢流淌，最耐看 |
| 涡旋 | 从画面中心拧开，像搅动一杯咖啡 |
| 故障 | 横向条带撕裂错位，赛博朋克味 |
| 马赛克 | 碎成方块，但每块都在呼吸 |
| 霓虹 | 只留边缘发光，照片变赛博线稿 |

- 手指按住画面拖动，可以局部推开色彩，像在湿颜料上划一道
- 导出 1080 × 1920 PNG，长按保存到相册，直接当手机壁纸

## 流彩 Aurora · 生成艺术壁纸

**[aurora-wallpaper.html](aurora-wallpaper.html)** — 不需要照片，直接生成无限流动的色彩星云。

- 8 套配色随机切换：极光 / 熔岩 / 深海 / 毒液 / 暮紫 / 琥珀 / 冰霜 / 猩红
- 手指按住屏幕搅动流体，松手后慢慢平息
- 导出 1080 × 1920 PNG

## 怎么用

**手机上**：把 html 文件传到手机（微信传文件、数据线都行），用浏览器打开。纯本地运行，不需要网络，断网也能用。

**电脑上**：直接双击打开，或者起一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/drift.html`。

**在线**：https://xiaxia0717.github.io/vibe-lab/

## 装成手机 App

这是标准的 PWA，可以像原生 App 一样装到手机上——独立图标、全屏运行、没有浏览器地址栏。

**iPhone / iPad（Safari）**

1. 打开 https://xiaxia0717.github.io/vibe-lab/drift.html
2. 点底部的「分享」按钮
3. 选「添加到主屏幕」
4. 桌面出现「浮影」图标，点开就是全屏

**Android（Chrome）**

1. 打开同一个地址
2. 点右上角三个点
3. 选「安装应用」或「添加到主屏幕」

装完之后，用起来和从应用商店下载的 App 没有区别。

## 技术

- 纯 WebGL 1.0 + 片元着色器，单文件零依赖，没有任何构建步骤
- 核心页面是**单文件自足**的（`drift.html` / `aurora-wallpaper.html`），双击就能跑；`manifest-*.json` + `sw.js` + 图标只是可选的 PWA 增强，删掉也不影响使用
- 核心算法是 domain warping：用噪声去扭曲噪声，再扭曲一次，产生无限流动、永不重复的图案
- 渲染分辨率压在 640px 宽以保证手机帧率，只有导出时才临时切到 1080 × 1920
- 照片处理全程在 GPU 完成，**不经过任何服务器**，隐私上是干净的

浏览器要求：支持 WebGL 的现代浏览器（Chrome / Safari / Edge / Firefox）。
