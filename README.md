# 手机变电脑外设：摄像头 · 麦克风 · 扬声器

把安卓手机变成电脑的外设。手机端是**原生 App**，打开就能用；
电脑端一个 Python 服务负责中转，并把它包装成系统能识别的虚拟设备。

```
┌─────────────┐   WebSocket    ┌──────────────────┐   虚拟摄像头 ──▶ 微信/会议/直播
│  手机 App   │ ─────────────▶ │  电脑端服务      │   虚拟麦克风 ──▶ 任何录音软件
│ 摄像头/麦克风│ ◀───────────── │  (server.py)     │   扬声器回传 ──▶ 手机播放
└─────────────┘   电脑声音      └──────────────────┘
```

## 一次性准备（只做一次）

### 1. 装虚拟摄像头驱动 → 双击 `安装OBS.bat`

装的是 OBS Studio（免费开源，200MB）。**装它只为拿自带的虚拟摄像头驱动**，
装完不需要打开 OBS。

### 2. 装虚拟声卡驱动 → 双击 `安装虚拟声卡.bat`

装的是 VB-Cable（免费）。装完**必须重启电脑**。

> 只想要摄像头、不在乎麦克风的话，这一步可以跳过。

### 3. 手机装 App

APK 已经装好了（桌面上的「手机摄像头」）。
如果换了手机或重装，执行：

```bash
D:\leidian\LDPlayer14\adb.exe install -r phone-cam-app\app\build\outputs\apk\debug\app-debug.apk
```

## 每次使用（三步）

### 1. 手机用数据线连电脑

手机需开启「开发者选项 → USB 调试」。

### 2. 双击 `phone-as-webcam\启动.bat`

脚本会自动完成：检查手机连接 → 建立端口转发 → 启动服务。
会弹出一个预览窗口，能看到手机画面。

### 3. 手机上打开「手机摄像头」App，点「启动」

- 电脑地址填 `127.0.0.1`，端口 `8080`（默认就是）
- 首次会请求相机和麦克风权限，点允许
- 状态变成绿色的「已连接」就成功了

## 在软件里怎么选

| 软件里的设置项 | 选择 |
|---|---|
| 摄像头 / Camera | **OBS Virtual Camera** |
| 麦克风 / Microphone | **CABLE Output** |

装完驱动后如果软件里找不到，**重启那个软件**（大多数软件只在启动时枚举设备）。

## App 界面说明

主界面只有**一个大按钮和三个开关**，打开就能用，不需要任何配置。

| 控件 | 作用 |
|---|---|
| 启动 / 停止 | 开始或结束推流（中间大按钮） |
| 切换镜头 | 前置 ↔ 后置摄像头 |
| 麦克风 | 是否把手机麦克风传给电脑 |
| 扬声器 | 是否播放电脑传回的声音 |
| 右上角齿轮 | 进入设置 |

预览区左上角是连接状态，右上角是实时帧率，右下角显示当前画质。

### 设置页

需要调整时点右上角齿轮。所有选项**改完即时生效、永久记住**：

- **连接** —— 电脑地址、端口（默认 `127.0.0.1:8080`，数据线连接时不用改）
- **默认画质** —— 分辨率、帧率
- **默认行为** —— 自动开始、默认前置摄像头、麦克风 / 扬声器默认开关
- **恢复默认设置** —— 一键还原

断线后会**自动重连**，不需要手动干预。

## 电脑端服务参数

```bash
.venv\Scripts\python.exe server.py --port 8080 --virtual-mic
```

| 参数 | 说明 |
|---|---|
| `--port` | 服务端口，默认 8080 |
| `--virtual-mic` | 把手机麦克风输出到 VB-Cable（供其他软件当麦克风） |
| `--no-mic` | 不输出手机麦克风声音 |
| `--no-speaker` | 不把电脑声音传回手机 |
| `--no-vcam` | 不启用虚拟摄像头 |
| `--no-gui` | 不显示预览窗口 |

## 常见问题

**App 显示"已断开"**
- 确认 `启动.bat` 已经跑起来（预览窗口开着）。
- 数据线重新插拔后，端口转发会失效，重跑一次 `启动.bat` 即可。

**微信里找不到 OBS Virtual Camera**
- 确认 OBS 装好了。
- **重启微信**——它只在启动时枚举摄像头设备。
- 可以先用系统自带的「相机」应用验证这个设备是否存在。

**对方听不到我说话（麦克风）**
- 确认虚拟声卡装好并**重启过电脑**。
- 软件里麦克风要选 `CABLE Output`（不是 `CABLE Input`）。
- 启动脚本要带 `--virtual-mic` 参数（`启动.bat` 已默认带上）。

**画面卡 / 帧率低**
- 暗光环境摄像头会自动降帧延长曝光，白天会明显更流畅。
- 可以降低分辨率或帧率试试。

**手机发烫**
- 长时间推流属于高负载场景，属正常现象。降低分辨率和帧率能缓解。

## 技术细节

- 传输协议：WebSocket 二进制帧，首字节标记类型 —— `0x01` JPEG 视频 / `0x02` PCM 音频
- 音频格式：16kHz / 单声道 / 16bit PCM
- 手机端：CameraX 采集 + `Bitmap.compress` 编码 JPEG；`AudioRecord` 采集；`AudioTrack` 播放
- 电脑端：aiohttp 收流；Pillow 解码；pyvirtualcam 输出虚拟摄像头；sounddevice 输出音频；soundcard 捕获系统声音
- 数据只在你的手机和电脑之间直连，不经过任何外部服务器

## 重新编译 App

电脑上的编译环境（已装好）：

```bash
cd phone-cam-app
set JAVA_HOME=%TEMP%\android-build\jdk-17.0.20.1+1
set ANDROID_HOME=%TEMP%\android-build\sdk
set GRADLE_USER_HOME=%TEMP%\gradle-home
%TEMP%\android-build\gradle-8.7\bin\gradle.bat assembleDebug
```

> 注意：`GRADLE_USER_HOME` 必须指向可写目录，否则会报"拒绝访问"。
