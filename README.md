# 手机变电脑外设：摄像头 · 麦克风 · 扬声器

把安卓手机变成电脑的外设。手机端是**原生 App**，打开就能用；
电脑端一个 Python 服务负责中转，并把它包装成系统能识别的虚拟设备。

```
┌─────────────┐   WebSocket    ┌──────────────────┐   虚拟摄像头 ──▶ 微信/会议/直播
│  手机 App   │ ─────────────▶ │  电脑端服务      │   虚拟麦克风 ──▶ 任何录音软件
│ 摄像头/麦克风│ ◀───────────── │  (server.py)     │   扬声器回传 ──▶ 手机播放
└─────────────┘   电脑声音      └──────────────────┘
```

## 一次性准备（本机已完成 ✅）

> 下面这些**已经全部装好并实测通过**，正常使用不需要再操作。
> 只有驱动坏掉需要重装时才看这一节。

### 1. 虚拟摄像头驱动（OBS Studio）

装 OBS Studio 只为拿它自带的虚拟摄像头驱动，装完不需要打开 OBS。

- 实际安装位置：`D:\Program Files\obs-studio`（C 盘空间不够，装到了 D 盘）
- 虚拟摄像头设备名：**OBS Virtual Camera**

> ⚠️ 踩坑记录：自检脚本早期写死了 `C:\Program Files\obs-studio`，
> 导致明明装好了却报"未安装"。现在改为**从注册表 `HKLM\SOFTWARE\OBS Studio`
> 读取安装路径**，并且**真实打开一次虚拟摄像头**来验证，不再看目录。

### 2. 虚拟声卡驱动（VB-Cable）

- 设备：**CABLE Input**（播放端）/ **CABLE Output**（录音端）
- 安装程序必须**以管理员身份运行**，否则报
  `LOADDRV: Acces denied to registry`。
- 装完**必须重启电脑**，驱动才会加载。

> ⚠️ **安装后遗症**：Windows 会把新装的 `CABLE Input` 设为**默认播放设备**，
> 结果是「电脑没声音 + 回环捕获到自己的声音导致回声」。
> 处理办法（两个都做了）：
> 1. `server.py` 自动检测并绕开虚拟声卡（`is_virtual_audio_name()`），
>    本机监听和回环捕获都改用一个真实扬声器；
> 2. 手动把系统默认播放设备改回真实设备
>    （设置 → 系统 → 声音 → 输出）。

### 3. 手机装 App

APK 已经装好了（手机上的「手机摄像头」）。
如果换了手机或重装：

```bash
D:\leidian\LDPlayer14\adb.exe install -r phone-cam-app\app\build\outputs\apk\debug\app-debug.apk
```

## 每次使用（三步）

### 1. 手机用数据线连电脑

手机需开启「开发者选项 → USB 调试」。

### 2. 双击桌面 `1-启动服务.bat`

脚本会自动完成：检查手机连接 → 建立端口转发（`adb reverse`）→ 启动服务。

- 想看到画面：去掉 `--no-gui`（默认就有预览窗口）
- 关掉那个窗口 = 停止服务

### 3. 手机上打开「手机摄像头」App，点「启动」

- 地址端口已经在 App 里固定好了（`127.0.0.1:8080`），**不用填任何东西**
- 首次会请求相机和麦克风权限，点允许
- 状态变成绿色的「已连接」就成功了

> 断线会自动重连（2.5 秒一次），中途重启电脑端服务也不用管手机。

## App 界面说明

主界面只有**一个大按钮和三个开关**，打开就能用，不需要任何配置。

| 控件 | 作用 |
|---|---|
| 启动 / 停止 | 开始或结束推流（中间大按钮，**点一下开、再点一下关**） |
| 切换镜头 | 前置 ↔ 后置摄像头 |
| 麦克风 | 是否把手机麦克风传给电脑 |
| 扬声器 | 是否播放电脑传回的声音 |
| 右上角齿轮 | 进入设置 |

预览区左上角是连接状态，右上角是实时帧率，右下角显示当前画质。

### 设置页

需要调整时点右上角齿轮。所有选项**改完即时生效、永久记住**：

- **连接** —— 电脑地址、端口（默认 `127.0.0.1:8080`，数据线连接时不用改）
- **默认画质** —— 分辨率、帧率
- **默认行为** —— 自动开始、默认前置摄像头、麦克风 / 扬声器默认开关
- **恢复默认设置** —— 一键还原

断线后会**自动重连**，不需要手动干预。

## 数据线 还是 WiFi？

两种都支持，**而且不用手动切**。

| | 数据线模式 | WiFi 模式 |
|---|---|---|
| 前置条件 | 电脑上跑一次 `adb reverse tcp:8080 tcp:8080` | 手机和电脑连同一个 WiFi |
| 电脑地址 | `127.0.0.1` | 电脑的局域网 IP |
| 稳定性 | 更稳，推荐 | 方便，无需插线 |

**自动发现**：App 连不上时会往局域网广播一句询问，电脑回自己的地址，
所以 WiFi 模式下**你不需要知道电脑 IP，也不用填** —— 路由器 DHCP 换了地址也不怕。
（实现见 `phone-cam-app/.../Discovery.kt` 和 `server.py` 的 `start_discovery_responder`，
用裸 UDP，端口 `47823`，不依赖任何第三方库。）

连接顺序：**上次成功的地址 → 设置里填的地址 → 自动发现**。
所以从数据线拔掉切到 WiFi、或者反过来，都会自己恢复。

## 电脑端服务参数

```bash
.venv\Scripts\python.exe server.py --port 8080 --virtual-mic
```

| 参数 | 说明 |
|---|---|
| `--port` | 服务端口，默认 8080 |
| `--virtual-mic` | 把手机麦克风输出到 VB-Cable（供其他软件当麦克风） |
| `--monitor` | **额外**把手机麦克风放到本机扬声器（调试用，默认关） |
| `--mic-gain N` | 麦克风音量增益，默认 `1.0`；对方说你声音小就调大（0.1-16） |
| `--open-preview` | 启动后自动用浏览器打开预览页 |
| `--no-mic` | 不输出手机麦克风声音 |
| `--no-speaker` | 不把电脑声音传回手机 |
| `--no-vcam` | 不启用虚拟摄像头 |
| `--no-gui` | 不显示预览窗口 |

> ⚠️ **本机这个 Python 没带 tkinter**，所以 `--no-gui` 那种 tkinter 预览窗口是用不了的。
> 服务会自动降级（不会崩），预览改用浏览器：`http://localhost:8080/preview`。
> 桌面脚本已经加了 `--open-preview`，双击后会自己弹出来。

### 关于 `--monitor`（本机监听）

**默认是关的，而且建议保持关闭。** 原因：电脑扬声器放出来的声音会被手机麦克风
再拾回去，形成声学回环 —— 对方会听到自己的回声。通话时你也不需要听自己的声音。

只有想单独验证"手机麦克风有没有在采"的时候才打开它。

## 常见问题

**App 显示"已断开"**
- 确认 `启动.bat` 已经跑起来（预览窗口开着）。
- 数据线重新插拔后，端口转发会失效，重跑一次 `启动.bat` 即可。

**微信里找不到 OBS Virtual Camera**
- 确认 OBS 装好了。
- **重启微信**——它只在启动时枚举摄像头设备。
- 可以先用系统自带的「相机」应用验证这个设备是否存在。

**对方听不到我说话（麦克风）**
- 确认虚拟声卡装好并**重启过电脑**。
- 软件里麦克风要选 `CABLE Output`（不是 `CABLE Input`）。
- 启动脚本要带 `--virtual-mic` 参数（`启动.bat` 已默认带上）。

**画面卡 / 帧率低**
- 暗光环境摄像头会自动降帧延长曝光，白天会明显更流畅。
- 可以降低分辨率或帧率试试。

**中途切到别的 App，画面会断吗？**
- **视频会暂停**，对方看到的是一张冻住的画面；声音不受影响（音频不绑生命周期）。
- 切回「手机摄像头」后**会自动恢复**，不用重新点启动（CameraX 回到前台会自己重开摄像头）。
- 所以通话时让这个 App 停在最前面就好。
- 实测数据：切后台前 `rx_frames=348` → 后台稳定在 `364` 不再增长 →
  切回后涨到 `598`，恢复。

**对方说我声音小**
- 启动时加 `--mic-gain 2.5`（或更大，最大 16）。
- 安静房间 + 手机降噪会把电平压得比较低，这是正常现象。

**手机发烫**
- 长时间推流属于高负载场景，属正常现象。降低分辨率和帧率能缓解。

## 技术细节

- 传输协议：WebSocket 二进制帧，首字节标记类型 —— `0x01` JPEG 视频 / `0x02` PCM 音频
- 音频格式：16kHz / 单声道 / 16bit PCM
- 手机端：CameraX 采集 + `Bitmap.compress` 编码 JPEG；`AudioRecord` 采集；`AudioTrack` 播放
- 电脑端：aiohttp 收流；Pillow 解码；pyvirtualcam 输出虚拟摄像头；sounddevice 输出音频；soundcard 捕获系统声音
- 数据只在你的手机和电脑之间直连，不经过任何外部服务器
