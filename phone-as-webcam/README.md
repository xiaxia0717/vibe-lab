# 手机当摄像头 / 麦克风 / 扬声器

把安卓手机变成电脑的外设：**摄像头（前后可切换）、麦克风、扬声器**。
手机端不用装 App，用浏览器打开一个网页就行。

```
手机浏览器  ──WebSocket──▶  PC 端服务  ──▶  虚拟摄像头 / 扬声器 / 麦克风
     ▲                          │
     └──────── 电脑声音回传 ─────┘
```

---

## 一、快速开始（数据线模式，推荐）

数据线模式最稳，而且手机访问 `localhost` 属于浏览器认可的"安全上下文"，
**不需要折腾 HTTPS 证书**就能调用摄像头。

### 1. 装依赖

```bash
cd phone-as-webcam
.venv/Scripts/pip.exe install -r requirements.txt
```

### 2. 把手机用数据线连上电脑

手机需开启「开发者选项 → USB 调试」。确认已连上：

```bash
D:\leidian\LDPlayer14\adb.exe devices
```

### 3. 建立端口转发

```bash
D:\leidian\LDPlayer14\adb.exe reverse tcp:8080 tcp:8080
```

这条命令让手机上的 `localhost:8080` 直接通到电脑的 8080 端口。

### 4. 启动服务

```bash
.venv/Scripts/python.exe server.py
```

### 5. 手机打开页面

在**手机浏览器**（推荐 Chrome）访问：

```
http://localhost:8080
```

点「开始」→ 允许摄像头和麦克风权限 → 电脑上的预览窗口就会出画面。

---

## 二、让微信 / 腾讯会议用上手机画面

这一步需要**虚拟摄像头驱动**。Windows 本身不提供，需要装 OBS Studio
（免费开源，它自带虚拟摄像头驱动）：

```bash
winget install OBSProject.OBSStudio
```

装完后重新启动本程序，你会看到：

```
[虚拟摄像头] 已启用 -> OBS Virtual Camera
```

然后在微信 / 腾讯会议 / 钉钉 的**摄像头设置**里，把设备选成
**「OBS Virtual Camera」**，画面就是你的手机了。

> 运行时**不需要**打开 OBS 软件，装一次就行。

---

## 三、同一 WiFi 模式（不用数据线）

直接让手机访问电脑的局域网地址：

```
http://<电脑IP>:8080
```

服务启动时会打印这个地址，例如 `http://192.168.1.8:8080`。

**注意**：浏览器规定只有 `localhost` 或 HTTPS 页面才能调用摄像头。
通过局域网 IP 用 HTTP 访问时，Chrome 会拒绝授权。两个解决办法：

- **推荐**：改用数据线模式（上面第一节），最省事。
- 或者在手机 Chrome 里打开 `chrome://flags/#unsafely-treat-insecure-origin-as-secure`，
  把 `http://192.168.1.8:8080` 加进白名单并重启浏览器。

## 四、参数说明

```bash
python server.py --port 8080        # 服务端口
python server.py --fps 30           # 虚拟摄像头帧率
python server.py --no-gui           # 不显示预览窗口（纯后台）
python server.py --no-vcam          # 不启用虚拟摄像头
python server.py --no-mic           # 不在电脑上播放手机麦克风声音
python server.py --no-speaker       # 不把电脑声音传回手机
```

## 五、手机页面上的功能

| 控件 | 作用 |
|---|---|
| 开始 / 停止 | 启动或停止推流 |
| 切换镜头 | 前置 ↔ 后置摄像头 |
| 麦克风 开/关 | 是否把手机麦克风声音传给电脑 |
| 扬声器 开/关 | 是否播放电脑传回的声音 |
| 分辨率 | 480p / 720p / 1080p |
| 帧率 | 15 / 24 / 30 fps |

页面会显示实时帧率和连接状态，并自动申请屏幕常亮（避免推流中断）。

### 免点击自动启动

在地址后面加 `?auto=1`，页面打开后会自动启动，不用手点「开始」：

```
http://localhost:8080/?auto=1
```

首次仍会弹一次系统的相机 / 麦克风授权框，点「允许」即可。
之后浏览器会记住授权，再打开就直接出画面。

> **关于手机浏览器**：推荐用 Chrome。国产浏览器（如 OPPO 自带浏览器）内核较旧，
> 可能不认 `inset`、`flex-gap` 这类较新的 CSS 属性而导致页面白屏。
> 本项目已改用兼容写法，**实测 OPPO 自带浏览器可正常显示并推流**。

## 六、常见问题

**手机页面打不开 / 一直"未连接"**
- 确认 `adb reverse` 那条命令执行过（每次重新插拔数据线都要重新执行一次）。
- 确认服务已启动，且预览窗口显示"等待手机连接…"。

**画面卡顿 / 延迟高**
- 把分辨率降到 480p、帧率降到 15 fps 试试。
- WiFi 模式下带宽波动大，数据线模式会明显更稳。

**电脑上听不到手机的声音**
- 检查预览窗口里"麦克风音频块"这个数字有没有在涨。
- 手机页面上的「麦克风」按钮要处于"开"的状态。

**虚拟摄像头启用了，但微信里找不到「OBS Virtual Camera」**
- 确认 OBS 装好了，然后**重启微信**（微信只在启动时枚举摄像头设备）。
- 也可以在系统的「相机」应用里先验证一下有没有这个设备。

**手机发烫、耗电快**
- 长时间推流属于高负载场景。降低分辨率和帧率能明显改善。

## 七、安全边界

- 本程序只监听局域网，不向任何外部服务器发送数据。
- 所有音视频都在你的电脑和手机之间直连，不经过第三方。
- 摄像头画面只在内存中处理，不写入磁盘。
